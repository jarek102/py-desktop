## Phase 1a — PanelRow + panel migrations
*Complete.*

### Approach (final)
Composition via `set_content_widget()`. Each panel *contains* a `$PanelRow`
in its `.blp`, sliders are built imperatively in Python `__init__` and placed
via `panel_row.set_content_widget(widget)`.

**`do_add_child` was attempted and failed** — PyGObject's GInterface virtual
method dispatch fires on ALL Box instances, not just PanelRow. Replaced with
the `set_content_widget` imperative approach.

### Tasks

- ✅ Create PanelRow widget (`ui/common/PanelRow.blp` + `src/ui/common/PanelRow.py`)
  - Exposes: `set_content_widget`, signals (`icon-activated`, `toggle-activated`, `chevron-activated`)
  - GObject properties: `icon-name`, `toggle-visible`, `toggle-active`, `chevron-visible`, `caption`, `caption-visible`
- ✅ Migrate BrightnessMenu to PanelRow composition
- ✅ Migrate VolumeMenu to PanelRow composition
- ✅ Fix BluetoothMenu favorites (restored inline ToggleButton approach, working)

### Key patterns established

- Slider binding chain: `Gtk.Adjustment.value ↔ self.value ↔ service.property` (two BIDI bindings)
- `GtkScale.value` is NOT directly bindable — always use `Gtk.Adjustment` as intermediary
- `@Gtk.Template` (and `@Blueprint`) classes CANNOT be subclassed — use composition
